# Snow Globe

A glass snow globe that changes season when it is shaken. Winter, spring, summer and fall, each with its own world inside the glass, its own base and its own light. Built in three.js.

This repo holds the plan for the build and, once the build has run, the build itself.

## Where things are

| Path | What |
| --- | --- |
| `AGENTS.md` | The rules the build follows |
| `kit/` | The plan, file by file. Start with `kit/00-README.md` |
| `kit/10-KICKOFF.md` | For Brandon: how to start the build, the review, and every prompt |
| `config/showcase.json` | Every number the plan sets |
| `references/approved/` | The eight approved images the build is held to |
| `references/drafts/` | The record of the reference run |
| `planning/` | Early planning notes |

## Status

The build is running. The log is `kit/PROGRESS.md`.

- The app as it stands: https://snow-globe-seasons.pplx.app
- The review page, where the newest pictures, films and sounds are in one place: https://snow-globe-seasons.pplx.app/review.html

Both open for a signed-in member of the organization that hosts them. Until the scene is built, the app shows a measuring spike made of plain shapes.

How to use it, how to render the films and how to deploy will be written here by the build.
