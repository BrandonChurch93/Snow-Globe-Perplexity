# The web pack: recipe

`public/assets/` is the set of files the published page fetches. Nothing in it is made by hand or by a part's own script: every file is derived, by one command, from a file of `assets-full/`, and each of those has its recipe in `assets-src/<part>/RECIPE.md`. `npm run make -- <part>` and then `npm run texpack` are the only way a file reaches this folder. `public/assets/index.json` is not part of the pack: `npm run build` writes it from what is in the folder.

## public/assets/
Made by: `tools/texpack.mjs` with `tools/lib/webset.mjs` (rule version `CODER = 5`), `tools/lib/glblevels.mjs` and `tools/lib/glbpack.mjs`, in Node 20; pictures through sharp 0.35.5 (libvips 8.18.7, libwebp 1.6.0), models through meshoptimizer 1.3.0 (its simplifier and its encoder)
From: every file of `assets-full/shared/` and `assets-full/<season>/` (the files named by the recipes of the parts: `assets-src/trunk/`, `tree-winter/`, `village/`, `village-winter/`, `base-winter/`, `frost-winter/`, `scene/`, `flakes/`), and `config/showcase.json` for the cap of the web set (`assetSets.web.baseMapPx` and `interiorMapPx`, 2048 px). A file keeps its folder and its name; a picture takes the ending of its coding.
Prompt or command: `npm run -s texpack` (all groups; `npm run texpack -- --group winter` for one, `--fresh` to make every file again without the cache in `out/work/texpack/cache/`, `--table` to print every file with its sizes, its coding and its largest change). What it does to each file:
- A picture (`.png`) is first sized as the web set always was: when its long side is over the `.wN.` in its name, or over the cap when the name has none, it is resized to that with the lanczos3 kernel; otherwise it is not resampled.
- `name.webp`: the sized picture as WebP near-lossless, `sharp.webp({ nearLossless: true, quality: 60, effort: 6 })`. The script decodes what it wrote and compares it with what went in: no channel of any pixel may differ by more than 2 of 255. A picture that fails is written as lossless WebP (`{ lossless: true, effort: 6 }`, which must decode to the same bytes), and if that fails too, or is not smaller than the PNG, it stays PNG. Today every picture passes: 34 near-lossless files, each with a largest change of exactly 2 of 255 or less.
- `name.first.webp`: only for an opaque picture whose long side is at least 1024 px and whose sides are even. It is the same picture at half the size, each 2 by 2 block averaged (in linear light for a `.srgb.` colour map, as plain numbers for a `.lin.` data map), which is the next mip level as the GPU would make it, coded and checked as above. The page draws the first picture from these and swaps the whole files in behind it.
- What stays `.png`, lossless: a picture with a side under 128 px (a table the shaders read as data, such as `shared/flake-lobes.lin.png`, 8 by 64, where one step of 255 is a different value and nothing is to be gained), a picture with fewer than three channels, and any picture the two WebP codings cannot hold within the rule.
- A model (`.glb`) keeps its name. First `addLevels` (`tools/lib/glblevels.mjs`) appends to every triangle mesh a lighter list of triangles for the `medium` and for the `low` quality level, made by `MeshoptSimplifier.simplifyWithAttributes` from the mesh itself with the option `ErrorAbsolute`: the surface stays within 0.03 mm (medium) and 0.1 mm (low) of the full one, the normals are weighed in at 0.5, no vertex is moved, added or dropped, and open edges and seams keep their vertices. A list is kept only when it holds at most 75 % (medium) or 90 % (low) of the triangles of the list above it; it is put in the order `MeshoptEncoder.reorderMesh` gives and named in `extras.levels` of its primitive. Then `packGlb` (`tools/lib/glbpack.mjs`) packs every stream with `EXT_meshopt_compression` (the file requires the extension): vertex streams in mode ATTRIBUTES with the EXPONENTIAL filter, which keeps them 32-bit floats and keeps 21 bits of a position, 16 of a normal or tangent, 20 of a texture coordinate, 14 of a colour and 24 of anything else; index lists in mode TRIANGLES, exact. The order of the vertices, every index of the full list, the names and the `extras` are kept. No second file is written for a level: the lists ride in the model.
- Any other file is copied as it is. Files left in a group's folder that the full set no longer names are removed.
Takes: 1. The command is deterministic: the same files of `assets-full/` and the same rule give the same bytes, which is why the page can name each file by the hash in `index.json`. It is run again after every `npm run make`, and the last run is what ships.
Why this one: near-lossless WebP is the lightest coding that changed no still of the harness to the eye (hero 53.8 dB and macro 51.6 dB against the lossless PNG set, largest change of a map 2 of 255) and a browser decodes it with no code of ours; KTX2 with UASTC and zstd was measured on the same pictures and came out both larger on the wire and less exact, so it is not used. The models lose only what the packing bits above say (at most 0.00012 mm of position). The pack is 21.97 MiB against 42.57 as lossless PNG and plain models, and the first picture needs 9.65 MiB of it.
